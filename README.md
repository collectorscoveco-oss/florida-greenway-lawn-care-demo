# Florida Greenway Lawn Care Demo Website

Static GitHub Pages demo for **TurfLead**, a custom lawn care website + simple CRM concept for solo operators and small crews.

Live site: https://collectorscoveco-oss.github.io/florida-greenway-lawn-care-demo/

## Current direction

Florida Greenway Lawn Care is now positioned as a sample/demo lawn care brand. The page shows how TurfLead can provide:

- A polished mobile-first lawn care website
- Demo quote request form
- Simple CRM preview with sample lead/customer/job data
- Starting-at website + CRM pricing
- Email/phone first calls-to-action
- Future integration path for Google Sheets, Zapier, Jobber, LawnPro, Yardbook, Google Calendar, Discord, and Telegram
